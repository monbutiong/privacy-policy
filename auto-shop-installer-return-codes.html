Installer Return Codes

Auto Shop Sales & Inventory System — how to interpret this installer's exit codes.

Applies to: Sales & Inventory System Setup.exe Installer technology: NSIS Silent switch: /S

Overview

The application is packaged with NSIS (Nullsoft Scriptable Install System) via electron-builder. It is a single self-contained installer — it does not download anything from the network during setup, does not replace any system files, and does not require a restart. Installed per-user (no administrator elevation required). Running it with the /S switch performs a fully silent, unattended installation.

Return codes

CodeMeaningResult
0 Installation completed successfully. Success
1 The installation was cancelled by the user before completion. Cancelled
2 A general installation failure occurred (for example, a file could not be written — including due to insufficient disk space, or the process being blocked by a security policy on the device). NSIS does not distinguish these failure causes with separate codes; all surface as this general failure code. Failure
Re-running the installer when the app is already installed (silent mode, /S) simply performs an in-place upgrade to the version being installed, and returns code 0 on success — there is no separate "already installed" code.

Scenarios that do not apply to this installer

  • Reboot required — never occurs. This is a standard userland desktop application; nothing it installs requires a system restart.
  • Network failure — not applicable. The installer is fully self-contained and does not contact the network at any point during installation.
  • Installation already in progress — the installer will not run a second concurrent instance of itself; if invoked while already running, the second invocation exits without altering the first.
