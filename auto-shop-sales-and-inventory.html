Privacy Policy

Auto Shop Sales & Inventory System — a desktop application for parts sales, purchasing, receiving, and stock management.

Effective date: September 1, 2026 Applies to: Auto Shop Sales & Inventory System (desktop application) Publisher: RamRam Dev

Overview

Auto Shop Sales & Inventory System ("the Application", "the Software") is a desktop application installed and run directly on your own computer. This policy explains what data the Application handles, where that data lives, and what control you have over it. If you're comparing this to a typical cloud or mobile app's privacy policy, the short version is: there isn't much to disclose, because your business data never leaves the computer (or local network) you choose to keep it on.

In one sentence: the Application does not send your business data, files, or usage activity to RamRam Dev, to any analytics provider, or to any other third party over the internet.

Data the Application Stores

The Application stores the business records you enter into it — inventory items, suppliers, customers, purchase orders, receiving vouchers, sales orders, quotations, adjustments, returns, receipts, user accounts, and related settings — in a local database file on the computer where the Application is installed.

WhatWhere it livesWho can access it
Business records (inventory, orders, customers, suppliers, transactions) A local SQLite database file on your device, inside your Windows user profile Only accounts you create inside the Application, per your own permission settings
Uploaded files (company logo, user avatars, adjustment attachments) A local folder alongside the database file Only accounts you create inside the Application
Login credentials Stored locally as a salted, one-way hash — never in plain text, never transmitted anywhere No one — not even an administrator can view another user's password

Local Network ("Host" / "Client") Mode

The Application can optionally be run in a networked mode, where one computer ("Host") holds the shared database and other computers on the same local network ("Client") connect to it so a team can work from the same records. In this mode, data travels only between the computers you configure on your own local network — it is never relayed through, or made accessible to, RamRam Dev or any external server.

What We Don't Do

  • We do not operate any server that the Application talks to. There is no cloud sync, no remote backend, and no account with RamRam Dev required to use the Software.
  • We do not collect analytics, telemetry, crash reports, or usage statistics from the Application.
  • We do not embed advertising or third-party tracking scripts.
  • We do not sell, rent, or share your business data, because we never receive it in the first place.

Data You Control

Because everything lives locally, you are entirely responsible for — and entirely in control of — your own data:

  • Backup: the Application includes a built-in backup feature that creates a copy of your database file, saved wherever you choose on your own system.
  • Export: reports and records can be exported to Excel (.xlsx) or PDF at any time, directly from the Application.
  • Deletion: uninstalling the Application does not automatically delete your data folder; you can locate and remove it yourself, or keep it for a future reinstall.

Children's Privacy

The Application is business software intended for use by adults operating or employed by an automotive parts or service business. It is not directed at children, and we do not knowingly collect any information from children.

Changes to This Policy
